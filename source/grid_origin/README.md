# Grid-origin computation sources

These scripts show the full saved-prediction integration and grid-selection procedure underlying the public CSV results. They require archived predictions, spatial metadata and receipts, which are not included in this release. Set SRPA_RECORDS_ROOT to your records archive and SRPA_ORIGINAL_CAMPAIGN to the original campaign path represented in its metadata. Default paths are relative. Do not use historical hashes to certify newly generated files. Run in a fresh directory with new freeze records when suitable inputs are available.

For the tested public workflow requiring only the supplied result tables, run analysis/summarize_and_plot.py from the repository root instead.
